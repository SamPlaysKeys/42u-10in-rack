# 05 — Panels

Blanking, vented, cable-entry and fan panels. The cheapest parts in the build and the
ones that most improve how it looks.

| Part | Qty | Status | Notes |
| :--- | :--- | :--- | :--- |
| `blanking-panel-1u` | TBD | Planned | Plain. |
| `blanking-panel-2u` | TBD | Planned | Plain. |
| `vented-panel-1u` | TBD | Planned | Slot pattern from `00-shared/vent-pattern.scad`. |
| `cable-entry-panel-1u` | 1 | Planned | Brush strip, at the top. |
| `fan-panel-1u` | 1 | Planned | 2× 40 mm, top exhaust. |

Note: a blanking panel is not just cosmetic. It stops the rack from recirculating its own
exhaust air between the front and the back, which matters more in a printed rack with no
door than it does in a cabinet.
