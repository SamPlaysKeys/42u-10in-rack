# 03 — Power

Mounts for PDUs, UPSes and power bricks.

Power bricks are the recurring complaint in every mini-rack build: they are the bulkiest
thing in the rack and they are never rack-shaped. Assume a mount is needed for each one
rather than assuming a shelf will do.

| Part | Qty | Status | Notes |
| :--- | :--- | :--- | :--- |
| `pdu-mount-1u` | 1 | Planned | For the chosen PDU. See ADR-0003 for depth. |
| `brick-cradle` | TBD | Planned | Universal-ish power brick holder. |
| `psu-shelf-1u` | TBD | Planned | For bricks that need to be flat. |
